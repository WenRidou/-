# 聊天记录查看器

把「响应」软件导出的聊天记录 HTML，变成响应风格的界面来看。

**功能**：会话列表、气泡对话、通讯录、收藏夹、置顶、拖拽排序、搜索、按日期/图片/便签/群成员查找、图片大图、语音播放、消息复制、**自动识别当前账号**。

## 需要准备

- Windows 电脑
- **Python 3**（只用一次，用来生成数据；生成后运行 exe 不再需要）
- 你自己从「响应」导出的那批聊天记录 html 文件

## 使用步骤

### 第 1 步：放入聊天记录
1. 解压本包后，得到一个文件夹，里面有 `ChatRecords.exe`、`ChatRecords.html`、`build_wechat.py` 和一个 **`html` 文件夹**。
2. 把你从「响应」导出的**聊天记录 html 文件全部放进 `html` 文件夹**（不要放到别处）。

### 第 2 步：生成数据
1. 双击 `build_wechat.js` 使用 `python(default)` 运行脚本；
或：在这个包根目录打开命令行，运行：
   ```
   python build_wechat.py
   ```
2. 按提示选择图片/语音处理方式：
   - 输入 `1`：**保留云端链接**（文件小，图片联网查看）
   - 输入 `2`：**下载到本地**（可离线查看；会先显示需要多少空间和实时进度条，确认后下载；若没装语音转换组件会先询问）
   - 输入 `3`：**补救**——把之前已下载但没转换成 mp3 的语音补转（无需重新下载）
3. 脚本会自动读取 `html` 文件夹里的聊天记录，生成 `data.js`（放到包根目录）；选 2 时还会在 `html` 文件夹里生成 `images`、`audio`。
   注：脚本运行完成后窗口会自动关闭，脚本运行过程中**请勿手动关闭窗口**。

### 第 3 步：打开查看器
1. 确认 `ChatRecords.exe`、`ChatRecords.html`、`data.js` 都在包根目录（默认就是）。
2. 双击 `ChatRecords.exe`。
   - 首次运行如出现 Windows SmartScreen 提示：点「更多信息」→「仍要运行」（未签名程序是正常现象）。

## 目录结构（解压后、使用前）

```
ChatRecords查看器/
├─ ChatRecords.exe
├─ ChatRecords.html
├─ build_wechat.py
├─ README.md
└─ html/
    ├─ （把你导出的聊天记录 html 全部放这里）
    ├─ images/   （选"下载到本地"后生成）
    └─ audio/    （选"下载到本地"后生成）
```

## 常见问题

- **语音没有声音？** 语音是 amr 格式，浏览器不支持播放，需要转成 mp3。选「下载到本地」时若未装转换组件，脚本会提示并**尝试自动安装**（`imageio-ffmpeg`）。若当时没转成功，之后**不用重新下载**：装好组件后再运行一次脚本、选 `3`，即可把已下载的语音补转成 mp3。纯云端模式（选 1）语音可能无法播放。
- **收藏/置顶/排序存哪？** 保存在 exe 旁边的 `wxchat_data.json`，把整个文件夹一起拷走即可随身携带。
- **换浏览器/清缓存丢收藏？** 用 exe 打开时数据写进文件，不受浏览器缓存影响。
